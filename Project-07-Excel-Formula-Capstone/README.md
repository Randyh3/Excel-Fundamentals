# Project 07 - Excel Formula Fundamentals & Advanced Formula Solutions

## Overview

This project demonstrates the core concepts and techniques required to build efficient Excel formula solutions. It covers formula construction, cell references, logical tests, operators, order of operations, text and number manipulation, date and time calculations, rounding, dynamic array formulas, Excel Tables, structured references, and formula auditing.

The project applies these concepts to practical business and financial scenarios, with an emphasis on building formulas that are efficient, flexible, scalable, and resistant to errors.

## What I Learned

```text
Built Excel formulas using cell references, operators, worksheet functions, and logical tests.

Applied Excel's Golden Rule by placing changing formula inputs into labeled cells and referencing those cells instead of hardcoding values directly into formulas.

Used relative, absolute, and mixed cell references to control how formulas behave when copied across rows and columns.

Applied keyboard shortcuts such as Alt+=, F4, and Ctrl+Shift+Down to improve formula-building efficiency.

Used Excel's default cell alignment to identify data types and help detect potential data-entry and formula errors.

Learned how number formatting changes the way values are displayed without changing the underlying value used by Excel formulas.

Applied the correct order of operations when building formulas involving mathematical, reference, and comparison operators.

Built logical formulas using comparative operators and Boolean logic to evaluate business conditions.

Used TEXTAFTER and TEXTBEFORE to extract information from text strings for use in lookup and data-retrieval formulas.

Converted numbers stored as text into actual numeric values using mathematical operations.

Used ROUND to control numerical precision when calculated values are used in subsequent formulas.

Applied MROUND, CEILING.MATH, and FLOOR.MATH for business scenarios requiring values to be rounded to specific increments.

Worked with Excel's date serial numbers and time serial values to perform date and time calculations.

Calculated elapsed days, working days, hours worked, and gross pay using Excel date and time formulas.

Built dynamic spilled array formulas to return and calculate multiple values without manually copying formulas.

Used Excel Tables and structured references to create formulas that automatically expand when new records are added.

Compared single-input/single-output formulas, dynamic spilled array formulas, Excel Table formulas, and scalar array formulas to understand when each approach is appropriate.

Used mixed cell references with conditional formatting to dynamically highlight records based on a selected value.

Used the Evaluate Formula tool to inspect how Excel calculates complex formulas and identify potential errors.

Applied formula auditing and formatting techniques to improve spreadsheet accuracy, readability, and reliability.

Focused on creating formula solutions that are scalable and adaptable rather than relying on manually entered or hardcoded values.
```
