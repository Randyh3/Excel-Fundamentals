# Project 05 - Logical Functions & IF Statements

## Overview

This project demonstrates Excel's logical functions used to automate decision-making, validate data, and build dynamic spreadsheets. It explores how logical tests evaluate TRUE and FALSE conditions and how the IF family of functions can be combined with logical, lookup, and information functions to solve real-world business and financial problems.

## What I Learned

    Built logical tests using comparison operators to evaluate TRUE and FALSE conditions.
    Used the IF function to automate business decisions based on defined criteria.
    Combined IF with AND, OR, and NOT functions to evaluate multiple conditions simultaneously.
    Applied ISNUMBER to validate imported data and identify non-numeric values.
    Used IFNA and IFERROR to create cleaner spreadsheets by handling missing values and calculation errors.
    Built dynamic invoice calculations by combining IF with XLOOKUP.
    Created formulas to calculate commissions, verify accounting balances, and automate business calculations.
    Learned how logical functions improve spreadsheet automation, accuracy, and efficiency.
