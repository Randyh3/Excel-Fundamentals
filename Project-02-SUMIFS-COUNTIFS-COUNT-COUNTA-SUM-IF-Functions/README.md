# Project 02 - Excel Functions & Conditional Analysis

## Overview

This project demonstrates fundamental Excel functions used for data analysis, financial reporting, and business decision-making. The exercises focused on building formulas to summarize datasets, perform conditional calculations, and analyze business information efficiently.

## Skills Demonstrated

    Basic Excel Functions
    Conditional Calculations
    Multi-Criteria Analysis
    Data Summarization
    Business Reporting
    Sales Analysis
    Cost Analysis
    Inventory Analysis

## What I Learned

    Applied SUM, COUNT, and COUNTA functions to summarize and analyze datasets.
    Used IF statements to create logical tests and automate decision-making within spreadsheets.
    Built COUNTIFS and SUMIFS formulas to analyze data using multiple conditions.
    Used conditional aggregation to calculate totals and counts based on specific criteria.
    Improved my ability to organize and analyze business data without relying on manual calculations.
    Developed Excel skills commonly used for financial reporting and FP&A analysis.

## Excel Functions Used

    SUM
    COUNT
    COUNTA
    IF
    COUNTIFS
    SUMIFS

## Why This Project Matters

Analyzing large amounts of business data efficiently is a key skill in finance and business analytics. This project strengthened my understanding of Excel formulas used for budgeting, reporting, KPI tracking, sales analysis, expense analysis, and other financial planning activities commonly performed in FP&A roles.
