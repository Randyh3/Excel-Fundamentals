# Project 06 - Lookup Functions & Data Retrieval

## Overview

This project demonstrates Excel's lookup functions used to retrieve, match, filter, and analyze data across spreadsheets. It explores how modern lookup functions can be used to perform exact and approximate lookups, return multiple records, compare lists, and solve real-world business and financial data retrieval problems.


## What I Learned

```
Used XLOOKUP to retrieve values from lookup tables using exact and approximate matches.
Built formulas to return entire employee records and columns of data using XLOOKUP.
Applied XLOOKUP to perform vertical, horizontal, two-way, and multiple-criteria lookups.
Used exact match or next smaller and exact match or next larger lookups for tax, commission, and pricing tables.
Used the LOOKUP function for efficient approximate-match lookups with sorted lookup tables.
Used FILTER to return multiple records based on a lookup value and solve duplicate-value lookup problems.
Applied XMATCH to compare two lists and identify values appearing in both or only one list.
Used SWITCH to select between multiple lookup tables based on a given product or category.
Created wildcard lookups using asterisks and question marks to perform partial text matching.
Used Data Validation dropdowns to improve lookup accuracy and prevent invalid lookup values.
Learned how modern Excel lookup functions improve spreadsheet automation, flexibility, and efficiency.
```
