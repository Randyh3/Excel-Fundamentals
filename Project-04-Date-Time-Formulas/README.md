# Project 04 - Date & Time Formulas

## Overview

This project demonstrates fundamental Excel date and time functions used for business calculations, reporting, and data analysis. It explores how Excel stores dates and times as serial numbers and how formulas can be used to calculate date differences, workdays, deadlines, employee hours, and payroll calculations.

## Skills Demonstrated

    Date Serial Numbers
    Time Serial Numbers
    Date Formatting
    Custom Number Formatting
    Date Calculations
    Workday Calculations
    Payroll Time Calculations
    Night Shift Calculations
    NETWORKDAYS.INTL Function
    WORKDAY.INTL Function
    EDATE Function
    EOMONTH Function

## What I Learned

    Understood how Excel stores dates as serial numbers and times as fractions of a 24-hour day.
    Used date formulas to calculate differences between dates, project timelines, invoice deadlines, and loan periods.
    Applied NETWORKDAYS.INTL and WORKDAY.INTL to calculate working days while excluding weekends and holidays.
    Used EDATE and EOMONTH to move dates by months and determine month-end dates.
    Extracted date information using YEAR, MONTH, DAY, and TEXT functions.
    Calculated employee hours worked, payroll totals, and overnight shifts using time formulas.
    Applied custom date and time formatting to improve spreadsheet readability and presentation.
